Terminologie-Entscheidungen

Pro inaktiviertem Code einen Nachfolger wählen (oder „kein Nachfolger“), optional eine Begründung. Exportieren lädt decisions.json herunter; die Datei ins Repo legen und termwatch decide erneut laufen lassen, dann wandern die Entscheidungen in die ConceptMaps. Auswahl wird im Browser zwischengespeichert.
